# Estoque Multiloja API — Design da v1.1.0

## Objetivo

A versão v1.1.0 evolui a API de estoque para incluir autenticação, usuários, permissões por perfil, vínculo de operadores com lojas, controle de estoque mínimo, alertas e novos filtros.

A versão preserva as funcionalidades já existentes da v1.0.1 e mantém compatibilidade com as regras de negócio do MVP.

## Escopo

A v1.1.0 inclui:

- usuários
- autenticação com JWT
- hash seguro de senha
- perfis admin e operador
- vínculo de operador com uma loja
- proteção dos endpoints
- ativação e desativação de usuários
- estoque mínimo por produto e loja
- alerta de estoque baixo
- filtros de produtos
- filtros adicionais de movimentações
- novos testes automatizados
- atualização da documentação
- atualização da versão da API para 1.1.0

Não fazem parte desta versão:

- frontend
- dashboard
- relatórios avançados
- refresh token
- recuperação de senha
- cadastro público
- multiempresa
- pagamentos
- sistema genérico de roles e permissions

## Usuários

Cada usuário possui:

- id
- nome
- email
- senha_hash
- perfil
- ativo
- loja_id

O campo email é único.

A senha nunca é armazenada em texto puro.

Usuários não são excluídos do banco. O administrador pode ativar ou desativar uma conta.

Usuário inativo não pode realizar login.

## Perfis

Existem dois perfis:

### Admin

O administrador possui acesso a todas as lojas e pode:

- criar usuários
- ativar e desativar usuários
- gerenciar usuários
- cadastrar, editar e excluir lojas
- cadastrar, editar e excluir produtos
- consultar todos os estoques
- consultar todas as movimentações
- registrar movimentações
- configurar estoque mínimo
- visualizar alertas de estoque baixo

O administrador não precisa obrigatoriamente estar vinculado a uma loja.

### Operador

O operador é obrigatoriamente vinculado a uma única loja.

O operador pode:

- consultar a própria loja
- consultar produtos
- consultar o estoque da própria loja
- consultar movimentações da própria loja
- registrar entradas e saídas na própria loja
- visualizar alertas de estoque baixo da própria loja

O operador não pode:

- criar usuários
- gerenciar usuários
- cadastrar, editar ou excluir lojas
- cadastrar, editar ou excluir produtos
- configurar estoque mínimo
- acessar ou movimentar estoque de outra loja

Tentativas de acessar outra loja retornam HTTP 403 Forbidden.

## Primeiro administrador

Não existe cadastro público de usuários.

O primeiro administrador pode ser criado por um script administrativo executado manualmente.

Exemplo:

```bash
python -m app.scripts.create_admin
